# Member 1 - Frontend and User Interface

## Your responsibility
Build the website screens and make the results understandable to the user.

## Step-by-step tasks
1. Create the homepage with project name, short explanation, and navigation.
2. Create a video-upload page with file selection, upload button, and clear upload status.
3. Create a dashboard showing processing status, pedestrian count, vehicle count, conflict count, and overall risk level.
4. Create a results area for alerts and a simple risk summary.
5. Create a reports page or downloadable summary only if time permits.
6. Use clear Low / Medium / High labels and make the layout usable on laptop screens.
7. Connect buttons and forms to the backend API when Member 2 provides the route details.
8. Show loading, success, and error states. Do not hard-code fake AI results.

## Expected deliverables
- Working HTML/CSS/JavaScript pages.
- Responsive dashboard and upload interface.
- Frontend API integration with documented endpoints.
- Short README explaining how to run the frontend.

## Suggested files
```text
frontend/index.html, frontend/dashboard.html, frontend/analysis.html, frontend/reports.html, frontend/style.css, frontend/script.js
```

## Integration handoff
Coordinate with Member 2 on upload and result API routes. Ask Member 2 for the exact JSON response and render those fields without renaming them.

## Before you finish
- Run your module and test it.
- Tell the team what files you created or changed.
- Share exact run commands and dependencies.
- Commit and push your work to your assigned Git branch.
